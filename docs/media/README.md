# Demo media

- [`walkthrough.mp4`](walkthrough.mp4): the author's complete approximately 83-second, silent walkthrough, resized to 1920 pixels wide and encoded as H.264/yuv420p MP4 with fast-start metadata. Playback speed and sequence are unchanged. A Markdown link opens the file; playback/download behavior depends on the repository viewer or browser.
- [`../images/planner.png`](../images/planner.png): the supplied planner/map screenshot, copied without visual edits.
- [`../images/itinerary-checks.png`](../images/itinerary-checks.png): the supplied itinerary/route-check screenshot, copied without visual edits.

The original 81 MB MOV remains outside the repository. The compact MP4 is included so the README has a working relative link before an external video-host URL exists. For larger recordings, prefer a GitHub release/attachment or video host and update the README link after upload.

These captures demonstrate this particular app session. Generated itineraries, images, provider matches, estimates, and response times can differ on another run. The footage includes both successful matches and unavailable photos rather than replacing provider results for the demo.

Screenshots/recording were provided for the project by its author. In-app photos and basemap imagery remain third-party material with their own attribution/licensing; this folder does not grant a new license for the underlying images or map data. Required in-app credit controls and map attribution were not cropped out.
